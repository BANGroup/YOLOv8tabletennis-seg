## Параметры YOLO Детекции

### Базовые параметры

| Параметр | Значение | Диапазон | Описание |
|----------|----------|----------|---------|
| `model_name` | `train10` | - | Используемая YOLO модель (v8-seg) |
| `confidence_threshold` | 0.25 | 0.0-1.0 | Минимальная уверенность детекции |
| `iou_threshold` | 0.45 | 0.0-1.0 | IoU для NMS (подавление дублей) |
| `device` | `0` | `0`,`cpu` | Устройство: GPU (0) или CPU |

### Классы объектов

| ID | Класс | Описание |
|----|-------|---------|
| 0 | Ball | Теннисный мяч |
| 1 | Net | Сетка |
| 2 | Player1 | Игрок 1 (левая сторона) |
| 3 | Player2 | Игрок 2 (правая сторона) |
| 4 | Table | Теннисный стол |

## Параметры Калман Фильтра

| Параметр | Значение | Единицы | Описание |
|----------|----------|---------|---------|

## Параметры Обнаружения Розыгрышей

### Детектирование начала/конца

| Параметр | Значение | Единицы | Описание | Статус |
|----------|----------|---------|---------|--------|

| `max_frames_outside` | 30 | кадры | Макс кадров вне видео (0.5 сек @ 60fps) | ✓ OK |

| `min_velocity_for_rally` | **2.0** | пиксель/кадр | Минимум скорости для старта rally | 🆕 ДОБАВЛЕНО |

| `min_direction_change` | 5 | градусы | Минимум смена для нового направления | ✓ OK |

| Параметр | Значение | Единицы | Описание |

## Параметры Обнаружения Sender/Receiver

### Определение стороны

| Параметр | Значение | Единицы | Описание |
|----------|----------|---------|---------|
| `table_center_x` | 0.5 | нормализованная | Центр стола по X |
| `left_side_boundary` | 0.5 | нормализованная | Граница левой половины |
| `right_side_boundary` | 0.5 | нормализованная | Граница правой половины |

### Логика Sender/Receiver

| Правило | Описание |
|--------|---------|
| **На левой половине стола** | Удар с левой стороны → Player1 (Sender), мяч к Player2 (Receiver) |
| **На правой половине стола** | Удар с правой стороны → Player2 (Sender), мяч к Player1 (Receiver) |
| **Обратный удар** | Если мяч летит НАЗАД (180°) → смена Sender/Receiver |

## 📝 ПРИМЕЧАНИЯ

### По производительности:
- Уменьшение `confidence_threshold` → ↑ CPU/GPU нагрузка
- Увеличение `min_rally_duration` → ↑ скорость обработки
- Параметры траектории не влияют на производительность

### По точности:
- `min_velocity` - очень эффективен против шума камеры
- `min_consecutive_detections` - исключает одиночные шумы YOLO
- `max_direction_change` - критичен для длинных rally

### По надежности:
- Использовать Калман фильтр для сглаживания
- Требовать 3+ кадра подряд перед началом
- Проверять скорость перед каждой детекцией
