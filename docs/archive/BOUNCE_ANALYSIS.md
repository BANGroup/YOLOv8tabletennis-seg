## 📊 СРАВНЕНИЕ ИСТОЧНИКОВ ИНФОРМАЦИИ

### Источник 1: fsm_logic.json (ключевой файл!)

```json
{
  "state": "Начало розыгрыша мяча",
  "conditions": {
    "bounce_S": 1,        ← BOUNCE SENDER (отскок на стороне Sender)
    "net_touch": 0,       ← Мяч не коснулся сетки
    "bounce_R": 1,        ← BOUNCE RECEIVER (отскок на стороне Receiver)
    "timeout": "1"        ← 1 кадр отсутствия (timeout)
  },
  "actions": {
    "score_S": 1,         ← Sender получил точку!
    "score_R": 0
  },
  "comment": "Конец розыгрыша"
}
```

**Ключевые переменные FSM:**
- **bounce_S** - Отскок мяча на стороне Sender (0=нет, 1=да)
- **bounce_R** - Отскок мяча на стороне Receiver (0=нет, 1=да)
- **net_touch** - Касание сетки (0=нет, 1=да)
- **timeout** - Длительное отсутствие мяча (null=нет, "1"=>0.5сек)

### Источник 2: IMPACT_DETECTION.md

**Критерии удара об стол:**
```
1. ✓ Y > height * 0.65      (в зоне стола)
2. ✓ Y движение: вниз→вверх (отскок)
3. ✓ Velocity > 2.0 px/frame (не шум)
4. ✓ Angle > 20°             (достаточный перелом)
5. ✓ min_consecutive = 3     (фильтр YOLO шума)
```

**Визуально:**
```
    Мяч летит вниз
         ↓
   ┌─────────────┐
   │   СТОЛ      │  ← Y > height * 0.65
   └─────────────┘
         ↑↑↑
   Мяч отскочил ВВЕРХ
   (УДАР ОБНАРУЖЕН!)
```

### Источник 3: SCORING_SYSTEM.md

## 🎯 ЛОГИКА ИЗ FSM: КАК РАБОТАЕТ ПОДСЧЕТ

### Сценарий 1: Player1 ударил, мяч вернулся
```
Условие:
- bounce_S = 1   (отскок на стороне Player1)
- bounce_R = 1   (отскок на стороне Player2)
- net_touch = 0  (не коснулась сетка)
- timeout = "1"  (мяч пропал > 0.5 сек)

Действие:
- score_S = 1    ← Player1 получил точку!
- score_R = 0

Интерпретация:
Player1 ударил → мяч полетел → Player2 не смог вернуть
(мяч вышел за пределы или Player2 не успел)
```

### Сценарий 2: Мяч коснулся сетки
```
Условие:
- bounce_S = 1
- net_touch = 1   ← СЕТКА!
- bounce_R = 1
- timeout = "1"

Действие:
- score_S = 0
- score_R = 1    ← Player2 получил точку!

Интерпретация:
Player1 ударил → мяч коснулся сетки → Player2 выигрывает
```

### Сценарий 3: Ошибка подачи
```
Условие:
- bounce_S = 1
- net_touch = 1   ← Коснулось сетки
- bounce_R = 0    ← Не долетело до другой стороны
- timeout = null  ← Сразу же

Действие:
- score_S = 0
- score_R = 1    ← Player2 выигрывает

Интерпретация:
Подача не прошла (коснулась сетки) → Receiver выигрывает
```

## 🔄 ЛОГИКА BOUNCE DETECTION

### Что нужно отслеживать:

```
TIMELINE МЯЧА:

T0: Player1 ударяет
    Position: На столе (Y > 0.65)
    Direction: Вниз (vy > 0)
    
T1: Мяч летит через сетку
    Position: Over net (0.4 < X < 0.6)
    Net_touch: Да или Нет?
    
T2: Мяч на стороне Player2
    Position: Y > 0.65
    Direction: Вниз (vy > 0)
    
T3: BOUNCE на стороне Player2! ← bounce_R = 1
    Position: Y -> вверх (vy < 0)
    Angle: > 25°
    
T4: Player2 или нет?
    Если Player2 ударяет → bounce_S изменяется
    Если нет → timeout увеличивается
```

### Условие для bounce:
```
bounce = True, если:
1. ✓ Y > threshold (на столе)
2. ✓ Velocity_before > 0 (летел вниз)
3. ✓ Velocity_after < 0 (летит вверх)
4. ✓ |Velocity_after| > min_velocity (не шум)
5. ✓ Angle_change > angle_threshold (достаточный перелом)
```
