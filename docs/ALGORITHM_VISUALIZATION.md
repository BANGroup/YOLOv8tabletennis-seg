## Оптимальные параметры (пресет "balanced")

| Параметр | Значение | Описание |
|----------|----------|----------|
| confidence | 0.03 | Порог уверенности YOLO |
| ball_min_area | 20 | Мин. площадь мяча (px²) |
| ball_max_area | 6000 | Макс. площадь мяча (px²) |
| min_frame_gap | 6 | Мин. кадров между ударами |
| curvature_threshold | 4 | Порог кривизны (px) |
| y_range_threshold | 8 | Порог Y-диапазона (px) |
| min_points_for_pattern | 3 | Мин. точек для анализа |
| max_missed_frames | 15 | Макс. пропущенных кадров |
