# Scoring Capsule — Подсчёт очков в настольном теннисе

## Scope
**Трогаем:** подача, двойной отскок, сетка, аут, счёт
**НЕ трогаем:** детекция ударов, YOLO модель, визуализация

## Invariants (≤12)

1. **Player 1 = левая сторона** (X < center_x)
2. **Player 2 = правая сторона** (X >= center_x)
3. **Смена подачи каждые 2 очка**
4. **Подача = пауза > 2.5 сек + подброс + удар на своей стороне**
5. **Двойной отскок = 2+ удара на одной стороне, интервал >= 0.5 сек**
6. **При двойном отскоке очко противнику**
7. **Сетка = мяч остановился около center_x**
8. **Аут = мяч вылетел за стол с высокой скоростью**

## Decisions (≤7)

| Решение | Обоснование |
|---------|-------------|
| Комбинированная подача (2/3) | Один признак ненадёжен |
| min_double_bounce_interval = 0.5 | Фильтрует ложные срабатывания |
| Сетка по траектории | Детекция Net класса ненадёжна |
| Аут только при высокой скорости | Фильтрует падение мяча на пол |

## Validation Proof

Проверить на видео:
1. Сетка на ~4 сек и ~9 сек (сегмент 60-120)
2. Правильное присуждение очков
3. Смена подачи каждые 2 очка

## Risks (≤7)

| Риск | Митигация |
|------|-----------|
| Ложный двойной отскок | min_interval = 0.5 сек |
| Пропуск сетки | Детекция по изменению траектории |
| Ложный аут при падении на пол | Требуем высокую горизонтальную скорость |
| Неправильная сторона | Только X-координата, без полигонов |
