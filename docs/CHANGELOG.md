## [23-01-2026] - Рефакторинг архитектуры v3

### ✅ Добавлено (Added)

**Модульная структура `scripts/core/`:**
- `kalman.py` — KalmanFilterWithGravity (6 состояний: x, y, vx, vy, ax, ay)
- `impact_detector.py` — SmartImpactDetector с dataclass конфигом
- `ball_tracker.py` — BallTracker с fallback зоной стола
- `visualizer.py` — TrackingVisualizer (отделён от логики)
- `__init__.py` — экспорт классов

**Новые файлы:**
- `scripts/main_processor_v3.py` — главный скрипт v3 с модульной архитектурой
- `scripts/config/detection_params_v3.json` — конфиг со всеми параметрами и пресетами

**Улучшения Калман фильтра:**
- Модель с гравитацией (ay ≈ 0.5 пикс/кадр²)
- Адаптивный шум измерений
- Предсказание на N кадров вперёд
- Автосброс после 30 пропущенных кадров

**Пресеты конфигурации:**
- `sensitive` — больше ударов, возможны ложные
- `strict` — меньше ложных, могут пропускаться

**Fallback зона стола:**
- Если YOLO не обнаружил полигон → используется прямоугольная зона
- Настраивается через `fallback_table_zone_*` параметры

### 🔧 Изменено (Changed)
- Все hardcoded пороги вынесены в конфиг
- Логирование через `logging` вместо `print()`
- Визуализация отделена от логики трекинга
- Документация ARCHITECTURE.md полностью переписана

### 🐛 Исправлено (Fixed)
- Устранено дублирование кода между v1 и v2
- Исправлен путь к модели в документации (`runs/segment/train10/` вместо `runs/detect/train10/`)
- Добавлена обработка отсутствия полигона стола

### 📊 Результаты
- Модульная архитектура готова к расширению
- Все параметры настраиваются через JSON
- Docker образ `tt-tracker:v1` готов

## [14-11-2025] - ВОГНУТАЯ траектория для обнаружения ударов

### ✅ Добавлено (Added)
- **SmartImpactDetector с вогнутостью** - Новая система обнаружения ударов по паттерну "вниз-вверх"
- **История траектории** - Ведение последних 10 точек в deque для анализа кривизны
- **Функция calculate_curvature()** - Вычисление отклонения середины траектории от концов
- **Загрузка параметров из JSON** - Config файл `scripts/config/detection_params.json`
- **CLI интерфейс** - Аргументы `--video`, `--start`, `--end`, `--config`
- **Исправленное вычисление fps_time** - Правильное использование глобального времени видео
- **Live impacts log** - Новый файл `results/current_run/live_impacts.json` со списком переломов
- **HUD обновление** - Счётчик ударов основывается на живых событиях + подсветка точек на столе
- **Min frame gap** - Параметр `min_frame_gap` объединяет близкие по кадрам переломы
- **Telemetry** - Для каждого удара фиксируется позиция касания, входная/выходная скорость и отображается в HUD/log

### 🔧 Изменено (Changed)
- **Логика detect_impact()** - Теперь проверяет вогнутость без требования мяча на столе
- **min_rally_duration** - Снижен с 0.3 до 0.05 сек для быстрых отскоков
- **min_consecutive_detections** - Снижен с 3 до 2 для более чувствительного обнаружения
- **Очистка истории** - Не очищается при каждом ударе, только при потере мяча >5 кадров
- **BallTracker.__init__()** - Добавлен параметр impact_params для загрузки из конфига
- **main_processor.py** - Передача параметров из конфига в SmartImpactDetector

### 🐛 Исправлено (Fixed)
- **Баг в process_detection()** - Исправлено `if self.consecutive_detections == self.consecutive_detections` на правильное условие
- **Баг fps_time на строке 280** - Использование правильной переменной из параметра функции
- **Финализация последнего ралли** - Добавлена явная финализация в конце видео
- **Расчет время видео в финале** - Используется корректный frame_idx с offset start_frame

### ⚠️ Результаты (Results)
- На сегменте 06:35-06:37 (2 сек): **Обнаружено 1 удар об стол**
- Система готова к дальнейшей оптимизации параметров
- Baseline для сравнения при итерациях параметров

### 📝 Статус
- ✅ ВОГНУТАЯ траектория как критерий удара - РАБОЧЕЕ
- ✅ CLI и конфиг - ГОТОВОЕ
