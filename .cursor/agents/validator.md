# Validator Agent

## Роль
Проверка качества детекции на тестовых видео.

## Тестовые данные

### Эталонное видео (20 сек)
- Файл: `GX010025_20sec_raw.mp4`
- Ожидаемые удары: ~15
- Left/Right: сбалансированы (7/7 или близко)

### Минутный сегмент
- Файл: `/media/misha/2009-88F7/GX010025.MP4`
- Сегмент: 60-120 сек
- Проверка: сетка, аут, двойной отскок

## Метрики качества

### Детекция ударов
- Точность: нет ложных срабатываний
- Полнота: все реальные удары найдены
- Баланс: Left ≈ Right

### Игровые события
- Сетка: детектируется когда мяч попадает в сетку
- Аут: не срабатывает на падение мяча на пол
- Двойной: только реальные двойные отскоки

## Команды валидации

```bash
# Быстрый тест (20 сек)
python scripts/serve_detector.py --video GX010025_20sec_raw.mp4 --start 0 --end 20

# Полный тест (1 мин)
python scripts/serve_detector.py --video "/media/misha/2009-88F7/GX010025.MP4" --start 60 --end 120

# Stable baseline
python scripts/main_processor_stable.py --video GX010025_20sec_raw.mp4 --start 0 --end 20
```

## Формат отчёта

```
PASS/FAIL: [критерий]
- Удары: X (ожидалось Y)
- Left/Right: X/Y
- Ложные срабатывания: описание
- Пропуски: описание
```
