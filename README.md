# 🎾 Table Tennis CV Score

**Система отслеживания и анализа мяча в настольном теннисе с помощью CV**

Система для автоматического обнаружения ударов мяча в настольном теннисе на основе YOLOv8 сегментации. Определяет когда мяч ударился об стол, **кто ударил** (sender) и **кто принимал** (receiver), отслеживая траекторию и визуализируя данные на видео.

---

## 🎯 Основные возможности

✅ **Детектирование мяча** - YOLOv8 сегментация (train10)  
✅ **Трекинг траектории** - Калман фильтр для сглаживания  
✅ **Обнаружение ударов** - Перломы траектории о стол  
✅ **Определение sender/receiver** - Кто ударил (левая/правая сторона)  
✅ **Визуализация** - Траектория, удары, время на видео  
✅ **JSON экспорт** - Данные об ударах и rally  
✅ **Потоковая обработка** - Обработка видео frame-by-frame

## 📊 Что обнаруживает система?

### 1️⃣ УДАРЫ (Impacts)
```
Система обнаруживает когда мяч ударяется об стол:
├─ Определяет: Player1 или Player2 ударил (по позиции X)
├─ Определяет: На какую сторону полетит мяч
├─ Критерии: Угол > 25°, скорость > 5 пиксель, Y > 85%
└─ Результат: Impact #1, #2, #3...
```

### 2️⃣ ПЕРЕЛОМЫ ТРАЕКТОРИИ (Trajectory Breaks)
```
Обнаруживает резкие изменения направления:
├─ Первоначальный удар (направление вниз)
├─ Вершина полета
├─ Возврат (направление вверх)
└─ Перелом = удар об стол (Impact)
```

### 3️⃣ РАСПРЕДЕЛЕНИЕ ПО СТОРОНАМ
```
На основе позиции X определяет:
├─ Левая сторона (X < 50%) → Player1 ударил
└─ Правая сторона (X > 50%) → Player2 ударил
```

### ⚠️ ПОКА НЕ РАБОТАЕТ
```
❌ Определение конца rally (кто ошибся)
❌ Подсчет очков (Points, Games, Match)
❌ Определение типа удара (serve, smash, lob)
```

## 🔍 Ключевые компоненты

### 1. **YOLOv8 Сегментационная модель** (train10)
```
Модель: runs/segment/train10/weights/best.pt
Классы: 
  - Ball (мяч)
  - Net (сетка)
  - Player1 (первый игрок)
  - Player2 (второй игрок)
  - Table (стол)
Точность: 95%+
```

### 2. **Калман фильтр**
```
Функция: Сглаживание траектории мяча
Преимущества:
  - Заполняет пропуски (когда игрок загораживает)
  - Предсказывает позицию
  - Фильтрует шум камеры
```

### 3. **SmartImpactDetector** (Детектор ударов)
```
Определяет: когда мяч ударился об стол
Логика:
  - Вертикальная смена направления (вниз→вверх)
  - Положение в зоне стола (Y > 65% высоты)
  - Минимальная скорость (> 2.0 пикс/кадр)
  - Угол перелома (> 20°)
Результат: Impact с sender/receiver
```

### 4. **Scoring Engine** (Движок счета) ⭐
```
Функция: Подсчет очков в реальном времени
Логика:
  - Rally: Последовательность ударов между игроками
  - Points: Кто выиграл rally (0 или 11 очков)
  - Games: Первый к 11 (с diff 2)
  - Match: Первый к 2 победам в играх
Результат: Full match score (2-1, Game score 11-9, Points 5-3)
```

### 5. **Логика Sender/Receiver**
```
Левая сторона стола (X < width/2):
  → Player1 ударил (sender)
  → Player2 принимает (receiver)

Правая сторона стола (X > width/2):
  → Player2 ударил (sender)
  → Player1 принимает (receiver)

Чередование: P1→P2→P1→P2→...
```

## 🔧 Как работает подсчет

```python
# 1. ОБНАРУЖЕНИЕ УДАРА
impact = {
    'time': 0.3,
    'sender': 'Player1',
    'receiver': 'Player2'
}

# 2. ОПРЕДЕЛЕНИЕ RALLY
rally = [
    {'sender': 'Player1', 'receiver': 'Player2'},
    {'sender': 'Player2', 'receiver': 'Player1'},
    {'sender': 'Player1', 'receiver': 'Player2'},
]
# Rally Player1 запустил, Player2 ошибся
rally_winner = 'Player1'

# 3. ДОБАВЛЕНИЕ ОЧКА
if rally_winner == 'Player1':
    score['player1'] += 1
else:
    score['player2'] += 1

# 4. ПРОВЕРКА ИГРЫ
if score['player1'] >= 11 and score['player1'] - score['player2'] >= 2:
    game_winner = 'Player1'
    games['player1'] += 1
    score['player1'] = 0  # Reset
    score['player2'] = 0

# 5. ПРОВЕРКА МАТЧА
if games['player1'] >= 2:
    match_winner = 'Player1'
    print(f"MATCH WON: {match_winner}!")
```

## 🐛 Известные проблемы и решения

### 1. Точность подсчета очков
```
Проблема: Нужно точно определить кто ошибся в rally
Решение: Анализировать последний удар перед концом rally
```

### 2. Определение конца rally
```
Проблема: Как понять, когда rally закончился?
Решение: Мяч ушел вверх после удара И не вернулся на стол
```

### 3. Производительность
```
Проблема: Full match обработка требует время
Решение: Оптимизация Kalman фильтра + многопоточность
```
