# Table Tennis CV Score

**Система автоматического подсчёта очков в настольном теннисе с помощью Computer Vision**

YOLOv8 сегментация + Kalman фильтр для трекинга мяча, детекции ударов, подач и подсчёта очков в реальном времени.

## Архитектура

### YOLO модель (train10)
```
Путь: runs/segment/train10/weights/best.pt
Тип: YOLOv8 Instance Segmentation

Классы:
  0: Ball      — мяч
  1: Net       — сетка  
  2: Player1   — игрок слева
  3: Player2   — игрок справа
  4: Table     — стол
```

### Алгоритм детекции удара
```
1. Вогнутая траектория (мяч шёл вниз → отскочил вверх)
2. Y-range >= 8 пикселей
3. Curvature >= 5
4. Точка внутри полигона стола
5. min_frame_gap = 12 кадров между ударами (~0.2 сек)
```

### Детекция подачи (v4_combined)
```
Комбинация 2/3 сигналов:
  - Пауза > 2.5 сек между ударами
  - Подброс мяча вверх (toss detection)
  - Первый удар на своей стороне
```

## Ключевые параметры

| Параметр | Значение | Описание |
|----------|----------|----------|
| `confidence` | 0.03 | Порог детекции мяча |
| `y_range` | 8 | Минимальное движение по Y для удара |
| `curvature` | 5 | Минимальная кривизна траектории |
| `min_frame_gap` | 12 | Кадров между ударами |
| `min_consecutive_detections` | 1 | Подряд точек для удара |
| `serve_pause_threshold` | 2.5 | Секунд паузы для подачи |
| `min_double_bounce_interval` | 0.5 | Секунд между двойными отскоками |

## Текущая работа

### Проблема: несбалансированный датасет
```
Распределение мяча в обучающих данных:
  Левая зона:  60%
  Центр:       20%
  Правая зона: 20%

Результат: модель хуже видит мяч справа
```

### Решение: дообучение
```bash
# 1. Найти кадры где модель пропускает мяч
python scripts/find_missed_balls.py --video GX010025_20sec_raw.mp4 --start 0 --end 20

# 2. Разметить кадры (вручную в CVAT/LabelImg)
# Кадры: results/missed_detections/frames_to_annotate/

# 3. Дообучить модель
python scripts/retrain_model.py --action full --epochs 30
```
