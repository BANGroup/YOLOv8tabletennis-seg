  bash results/roboflow_pipeline/run_video.sh

Gameplay window (IMG_0291): 45–180 сек (первые ~2.5 мин игры, без warmup).
Стратифицированная выборка: 80 равных временных бинов, max 1 кадр/бин.
Gameplay gate: --require-table-ball (мяч y>0.45 или скорость > порога).

Player spatial rule (prelabel_yolo_seg.py):
  train12 cls 2/3 игнорируется; Player1/Player2 по center_x vs split_x (сеть).
  Дедуп IoU>0.5 на стороне, max 2 игрока на половину.

Шаги run_video.sh:
  1. sample 80 кадров из IMG_0291.MOV (45–180 сек, stratified+combined)
  2. pre-label train12 -> YOLO seg polygons + Ball bbox (prelabel_yolo_seg.py)
  3. zip images/ + labels/ (--format seg, без Ball)
  4. upload вручную: upload_batch.py (после создания tt-seg-img0291 в UI)

=== Формат labels (hybrid_seg, merged labels/) ===
  0-4 seg: TableLeft, TableRight, Net, Player1, Player2 (polygon lines)
  5 det:   Ball cx cy w h (5 values, local only; excluded from seg upload zip)

=== Классы Roboflow seg upload (5) ===
  TableLeft, TableRight, Net, Player1, Player2

=== Legacy det classes (pilot) ===
  0 Ball, 1 Net, 2 Player1, 3 Player2, 4 Table

=== Autolabel matrix (M2 ontology — seg only, без Ball) ===
  Net, TableLeft, TableRight, Player1, Player2

=== Troubleshooting ===
  - ROBOFLOW_API_KEY: проверить .env в корне проекта
  - seg project tt-seg-img0291: создать в UI если upload вернул ошибку проекта
  - batch_id null: скопировать из Roboflow UI Annotate tab в state.json
  - Float32 координаты в prelabel_yolo_seg.py
